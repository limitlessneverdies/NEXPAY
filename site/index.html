Honest security.

No hype. What this is and isn't:

  • Test credit only. No bank, no KYC, no cash-out, no real NPR. The server refuses real-money mode.
  • Offline double-spend is unsolved — a compromised phone can sign one note twice; only the first redemption settles. Disclosed, tested, and shown in the UI.
  • APKs can be unpacked. R8 obfuscation raises the cost; issuer keys stay on the server, never in the app.
  • No account recovery. Uninstalling loses the test wallet. Never use with real funds.
